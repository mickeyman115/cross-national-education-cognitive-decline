# Data access and non-redistribution

No individual-level cohort data are included in this repository. The scripts
require authorised copies of the following harmonised products:

- Harmonized CHARLS, Version D (June 2021)
- RAND HRS Longitudinal File 2020, Version 2 (May 2024)
- Harmonized ELSA, Version G.3 (June 2023)
- Harmonized SHARE, Version F (June 2022; based on SHARE release 8.0.0)

Researchers must register with and obtain the data from the respective data
custodians, then comply with all applicable data-use conditions. Set the local
paths through `HRS_FILE`, `ELSA_FILE`, `SHARE_FILE`, and `CHARLS_FILE`; do not
copy the files into this repository.

The public `results/` directory contains only aggregate statistical outputs.
It does not contain participant-level records or model objects.
